# Phase 2 总推进

Phase 1 的逐步记录见 [[00-项目总推进]]。本页接在它之后，回答同一个问题：**相对最初的设想，现在走到哪了。**

> **口径。** 每个结论只标注三种状态之一：**已验证**（有可复现的运行证据或测试）、**已实现未验证**（代码在，但缺独立验证）、**未做**。不使用"大致完成"这类无法反驳的说法。
>
> **更新规则。** 每个里程碑收口时更新，追加到末尾的更新记录，不覆盖历史判断。数字来自代码与运行产物，不凭印象填写。

## 阶段位置

```text
Phase 1   Isaac Sim 刚体接触基线        Step 01 – 06.6 冻结，Step 07 原型
            ↓  边界：迁移为 InteractionState v2 + ExperimentManifest
```

Phase 1 把层 2 做到了**可冻结**；Phase 2 把层 2 的**边界**冻结，并把层 3–5 从零变成"有记录、有状态标记、但内容很薄"。

## 收尾结论（2026-11-25）

**在不依赖 Isaac Sim 的前提下，做出了自己的刚体触觉内核和五层链路骨架；与 Isaac Sim 5.1.0 比对，参数对齐时两边一致。** 范围限定为单球探头、刚体、零摩擦、法向接触。

| 当初的目标 | 结果 |
| --- | --- |
| 跳过 Isaac Sim，有自己的触觉内核 | ✅ 内核和测试不依赖 Isaac，CPU 可跑，325 个测试 |
| 内核结果可信 | ✅ 参数对齐时逐帧法向力差小于 2×10⁻⁷ N，接触起始、法线、相位、帧数、力控稳态相同（[[17-Phase2收尾-Isaac比对]]） |
| 五层链路打通 | ✅ 骨架通；层 1、2 有内容，层 3–5 是占位 |
| 外部参照 | ✅ 第一个和仓库外部比对过的数字 |

**收获**

1. **解耦可行，并且有证据。** Phase 3 可以放心把这个内核当作层 1 的几何与运动学引擎、物理基线。
2. **Phase 1 的默认参数并不中性。** Isaac 默认动摩擦 1.0 让滑动漂移 49 mm；直接拿 Isaac 当真值，会把参数偏差当成物理结论。
3. **不同引擎的约定必须写进契约。** PhysX 在一步开始生成接触，内核在一步结束记录，天然差一步。
4. **Phase 2 乱，不是技术问题，是验收由谁来定的问题。** 门槛由执行方自己定，越加越多，验证的都是代码自洽；主线三周换四次；进度条分母不断变。收尾一天就做完，是因为三个条件同时满足：**阈值由用户来定、写死在代码里，有时间盒，明确写出不做什么。** 这一条是 Phase 3 的工作规则。
5. **自洽门槛防退化，外部参照判方向。** 两者都需要，外部参照要尽早引入。

## 最初设想的三件事

当初设想是三件事：**冻结协议、解耦触觉核、引入后续各层形成闭环**。推进很不均匀，分开说才有意义。

| 设想 | 状态 | 已经做到的 | 还差的 |
| --- | --- | --- | --- |
| **冻结协议** | 关键一条已冻结 | `InteractionState v2` 带版本 Schema 并哈希绑定；`ExperimentSpec v1`、`ExperimentManifest v1` 同样冻结 | 层 3/4/5 的记录仍是进程内接口，不是带版本契约 |
| **解耦触觉核** | **完成并验证** | 内核与链路对 Isaac Sim 的 import 为 **0**（只有三个上机工具脚本导入）；`contact_kernel/` 仅依赖 `math` 与 `dataclasses`；325 个测试不需要仿真器或 GPU；对齐参数下与 Isaac 一致 | 摩擦、切向力、盒形探头、多探头未比对 |
| **各层闭环** | 结构闭环，内容未闭环 | 五层每个控制步都必须产出记录，缺失抛异常；轨迹与力控两种模式都走完全链路 | 层 3 是透传、层 4 只有一个通道、层 5 没有硬件 |

**一句话概括：管道通了，内容还薄。**

这不是谦辞，而是对照最初路线的结论。原始路线的"阶段一"定义是：

> 单指尖、**三种**虚拟材料、法向力与**振动**双输出的触觉解算器。

现在是：单指尖、**一种**刚体材料（且层 3 为透传）、**一个**法向力通道。Phase 1 与 Phase 2 实际建成的，是这个目标**下面的那层地基**——接触检测、证据契约、五层骨架、验收护栏。地基比原计划扎实得多，但"三种材料 + 振动"一项都还没开始。

**当前位置更准确的描述不是"阶段一完成了多少"，而是"阶段一的地基已经打完，阶段一本身还没动工"。**

## 两个阶段的共同盲区

两个阶段的全部门槛都在验证**代码与自己一致**：力与冲量互相对得上、改时间步结果不变、哈希能复现、Point 加总等于 Patch。

没有一项和仓库外面的世界比过——没有和真实测量比过，没有和人的感知比过。

内部自洽的门槛能防止代码退化，但不能告诉方向对不对。

**收尾时的状态**：刚体物理层有了外部参照（Isaac）；层 2、3 的接触与材料仍没有和真实世界比过，这是 Phase 3 用真实指尖数据要补的。
