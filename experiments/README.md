# Experiment Records

该目录存放按运行 ID 组织的实验产物索引。大体积原始日志和模型文件不进入版本库，清单和哈希记录保留在版本库中。

| 位置 | 内容 | 是否入库 |
| --- | --- | --- |
| `runs/<run_id>/` | 完整产物：`streams/*.jsonl`、CSV、诊断、`manifest.json` | 否 |
| `index/<spec_id>.json` | 运行身份、规格与条件哈希、清单哈希、段统计、门槛结果、产物哈希清单 | 是 |

索引让后续阶段能找到某轮运行、确认它由哪份规格产生、看到门槛是否通过，而不必加载数兆的逐帧数据。`runs/<run_id>/replay_check.json` 是清单写完之后的回放校验，不属于清单产物。
