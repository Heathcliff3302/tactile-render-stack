# ExperimentManifest v1

`ExperimentManifest` 描述一轮可复现实验。它把逐帧状态绑定到场景、输入轨迹、材料、时间基准、后端版本和产物文件。

## 清单内容

| 组 | 必须记录 |
| --- | --- |
| 场景身份 | 场景 ID、场景版本、运行 ID |
| 后端 | 后端 ID 和后端版本 |
| 物理条件 | 参考坐标系、探头、表面、材料和参数 |
| 时间条件 | 起止时间、物理步长、输出步长 |
| 输入轨迹 | 轨迹 ID、时间、位置和速度采样 |
| 观测量 | 定义 ID、单位、计算方法、支持区域和所属质量组 |
| 验收条件 | 预期帧数、必须观测量和缺失比例上限 |
| 产物 | 相对路径、产物角色和 SHA-256 |

## 运行验收

验收器检查以下关系：

1. 实验条件摘要与清单内容一致。
2. 逐帧数据使用同一个运行 ID、场景 ID 和条件摘要。
3. 帧序号连续，时间单调，时间间隔符合清单。
4. `body0` 和 `body1` 顺序固定。
5. 有效观测量的计算方法与清单一致。
6. 必须观测量在允许的缺失比例内可用。
7. 产物路径保持在运行目录内，文件哈希一致。

## 比较门槛

两个后端只有在以下条件一致时才进入趋势比较：

- 场景 ID 和版本
- 物理条件摘要
- 输入轨迹和时间基准
- 观测量单位和定义
- 离散网格或核函数支持区域

比较门槛通过后，报告仍需分别给出力、形变和压力的趋势指标。门槛通过不代表两个求解器得到相同数值。
